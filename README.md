# Школа Елены Носовской - версия для обсуждения

Для GitHub Pages загружается только index.html. В нём встроены стили, скрипты, шрифты и два портрета Елены.

14 адресуемых страниц программ через #course-ID. Встроены 11 полных статей школы; базовый буккальный курс содержит план по дням. Отдельной полной программы буккального самомассажа среди найденных материалов нет: на его странице оставлено подтверждённое описание, без выдуманного плана.

Сайт содержит noindex/nofollow. Это публичный черновик для обсуждения, а не смена действующего сайта bestmassaj.ru. Заявки автоматически не отправляются.

Исходники для правок лежат в source/. В репозиторий не нужно загружать документы Drive, отчёты, резервные версии или медиабазу.
