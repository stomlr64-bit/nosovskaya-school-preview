# Школа Елены Носовской - рабочая версия

Сайт: https://stomlr64-bit.github.io/nosovskaya-school-preview/

Для публикации используется index.html со встроенными стилями, шрифтами, скриптами и портретами всех шести педагогов. Четыре векторные обложки обозначают направления обучения.

14 страниц программ, 11 полных статей школы. Отдельная полная программа буккального самомассажа пока отсутствует в найденных источниках.

Цены и продолжительность для группы и индивидуального обучения перенесены из https://nosovskaya-seminars.netlify.app/ 2 октября 2026 года. Суммы за одного участника, для Москвы. Региональные цены уточняются у организаторов.

Сайт публичный; noindex/nofollow просит поисковики не индексировать рабочую версию. Автоматической отправки заявок нет. Действующий сайт bestmassaj.ru не изменён.

Локальные исходники: source/. Для повторной сборки с ценами и визуалами используется work/update_school_prices.py, который сначала собирает базовую версию, затем применяет эти изменения. Исходные документы и медиабаза на GitHub не загружаются.
